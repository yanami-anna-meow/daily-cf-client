# Daily CF Client v0.3.24

The first packaged release of Daily CF Client, a desktop app for [Yawn-Sean's Daily CF Problems](https://github.com/Yawn-Sean/Daily_CF_Problems).

Browse the full archive, read hints and editorials, view everyone's reference code, and collect your solutions into one GitHub pull request. The app includes English and Chinese interfaces, light and dark themes, and editable color schemes. The problem library updates through Git and remains readable while an update is in progress.

## Downloads

Choose your operating system and processor. `x64` is for Intel and AMD processors; `arm64` is for ARM processors, including Apple Silicon and Windows on ARM.

| System | Processor | Files |
| --- | --- | --- |
| Windows | x64 | `Daily-CF-0.3.24-x64-nsis.exe` (installer), `Daily-CF-0.3.24-x64-portable.exe` |
| Windows | ARM64 | `Daily-CF-0.3.24-arm64-nsis.exe` (installer), `Daily-CF-0.3.24-arm64-portable.exe` |
| macOS | Intel | `Daily-CF-0.3.24-mac-x64.dmg`, `Daily-CF-0.3.24-mac-x64.zip` |
| macOS | Apple Silicon | `Daily-CF-0.3.24-mac-arm64.dmg`, `Daily-CF-0.3.24-mac-arm64.zip` |
| Linux | x64 | `Daily-CF-0.3.24-linux-x86_64.AppImage`, `Daily-CF-0.3.24-linux-amd64.deb` |
| Linux | ARM64 | `Daily-CF-0.3.24-linux-arm64.AppImage`, `Daily-CF-0.3.24-linux-arm64.deb` |

On macOS, open the DMG and copy the app to Applications, or extract the ZIP. On Linux, make the AppImage executable before opening it; DEB packages are for Debian and Ubuntu systems. GitHub's automatically generated source archives contain the source code, not an installed application.

`SHA256SUMS.txt` lists the checksums of all twelve packages. Windows packages are unsigned. macOS apps use an ad-hoc signature, without an Apple Developer ID certificate or notarization. The operating system may show a security warning.

## Validation and limits

The release workflow runs the automated tests for every target and checks the packaged executable's architecture, bundled application files, and installer names. It also starts the packaged application on Windows x64, macOS Intel, and Linux x64 and ARM64. Windows ARM64 and macOS Apple Silicon packages are cross-built and checked statically; they have not been run on those devices. These checks do not replace testing every installer on a physical device.

Read the [user guide](https://github.com/yanami-anna-meow/daily-cf-client/blob/main/docs/user-guide.md) for login, library updates, and submissions. Report problems in [Issues](https://github.com/yanami-anna-meow/daily-cf-client/issues), including your system, processor, and the package you downloaded.

这是客户端的第一个安装包版本。可以浏览小羊肖恩的完整题库，阅读提示、题解和所有用户的参考代码，将自己的解答加入提交列表，再统一创建一个 GitHub PR。支持中英文界面、深浅色主题和自定义配色；题库通过 Git 更新，更新期间仍可阅读已有内容。

下载时按上表选择系统和处理器：Intel、AMD 电脑通常选 `x64`；Apple Silicon、Windows ARM 电脑和 ARM Linux 设备选 `arm64`。Windows 的 `nsis.exe` 是安装版，`portable.exe` 是免安装版；macOS 提供 DMG 和 ZIP；Linux 提供 AppImage 和 DEB。GitHub 自动生成的 Source code 压缩包是源码，不是客户端安装包。
