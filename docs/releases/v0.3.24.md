# Daily CF Client v0.3.24

## English

The first packaged release of Daily CF Client, a desktop app for [Yawn-Sean's Daily CF Problems](https://github.com/Yawn-Sean/Daily_CF_Problems).

Browse the full archive, read hints and editorials, view everyone's reference code, and collect your solutions into one GitHub pull request. The app includes English and Chinese interfaces, light and dark themes, and editable color schemes. The problem library updates through Git and remains readable while an update is in progress.

### Downloads

Choose your operating system and processor. `x86_64` is for Intel and AMD processors; `arm64` is for ARM processors, including Apple Silicon and Windows on ARM.

| System | Processor | Files |
| --- | --- | --- |
| Windows | x86_64 | `Daily-CF-0.3.24-windows-x86_64-nsis.exe` (installer), `Daily-CF-0.3.24-windows-x86_64-portable.exe` (portable) |
| Windows | ARM64 | `Daily-CF-0.3.24-windows-arm64-nsis.exe` (installer), `Daily-CF-0.3.24-windows-arm64-portable.exe` (portable) |
| macOS | Intel | `Daily-CF-0.3.24-macos-x86_64.dmg`, `Daily-CF-0.3.24-macos-x86_64.zip` |
| macOS | Apple Silicon | `Daily-CF-0.3.24-macos-arm64.dmg`, `Daily-CF-0.3.24-macos-arm64.zip` |
| Linux | x86_64 | `Daily-CF-0.3.24-linux-x86_64.AppImage`, `Daily-CF-0.3.24-linux-x86_64.deb` |
| Linux | ARM64 | `Daily-CF-0.3.24-linux-arm64.AppImage`, `Daily-CF-0.3.24-linux-arm64.deb` |

On Windows, run the installer or open the portable version directly. On macOS, open the DMG and copy the app to Applications, or extract the ZIP. On Linux, make the AppImage executable before opening it; DEB packages are for Debian and Ubuntu systems.

GitHub's automatically generated source archives contain the source code, not an installed application.

### Checksums and signatures

`SHA256SUMS.txt` lists the checksums of all twelve packages. Filenames use `windows`, `macos`, or `linux` for the system and `x86_64` or `arm64` for the architecture. Renaming the files did not change package contents. Earlier checksum lists are retained for copies downloaded under previous filenames.

Windows packages are unsigned. macOS apps use an ad-hoc signature, without an Apple Developer ID certificate or notarization. The operating system may show a security warning.

### Validation and limits

The release workflow runs the automated tests for every target and checks the packaged executable's architecture, bundled application files, and installer names. It also starts the packaged application on Windows x86_64, macOS Intel, and Linux x86_64 and ARM64. Windows ARM64 and macOS Apple Silicon packages are cross-built and checked statically; they have not been run on those devices. These checks do not replace testing every installer on a physical device.

Report problems in [Issues](https://github.com/yanami-anna-meow/daily-cf-client/issues), including your system, processor, and the package you downloaded.

Windows 用户可以运行安装程序，或直接打开免安装版。macOS 用户可以打开 DMG，将应用复制到“应用程序”文件夹，或解压 ZIP。Linux 用户需要先为 AppImage 添加执行权限再打开；DEB 安装包适用于 Debian 和 Ubuntu 系统。

GitHub 自动生成的源码压缩包包含源代码，不是可直接使用的客户端。

### 校验与签名

`SHA256SUMS.txt` 列出了全部 12 个安装包的校验值。文件名中的系统使用 `windows`、`macos` 或 `linux`，架构使用 `x86_64` 或 `arm64`。文件改名没有改变安装包内容。之前的校验清单仍然保留，供按旧文件名下载的文件使用。

Windows 安装包未签名。macOS 应用使用临时签名（ad-hoc），没有 Apple Developer ID 证书，也未经过公证。操作系统可能显示安全提示。

### 验证与限制

发布流程会为每个构建目标运行自动测试，并检查打包后可执行文件的架构、应用文件和安装包名称。还会在 Windows x86_64、Intel Mac，以及 Linux x86_64 和 ARM64 上启动打包后的应用。Windows ARM64 和 Apple Silicon 版本通过交叉构建生成，只做了静态验证，尚未在对应设备上运行。这些检查不能替代在实体设备上对每种安装包进行完整测试。
