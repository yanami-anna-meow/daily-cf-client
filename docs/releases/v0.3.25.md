# Daily CF Client v0.3.25

## English

This release adds **Settings → App updates**. Check the latest release, read its notes and choose to download a package for your current system, architecture and package type. No GitHub sign-in is needed.

Downloads show progress, support cancellation and retry, and are checked for their exact size and SHA-256. Opening a downloaded installer requires another confirmation; the app does not install silently or restart itself. Portable and AppImage users receive a file to replace after quitting. Version 0.3.24 has no updater, so install 0.3.25 manually once to use this feature for future releases.

### Downloads

Choose your operating system and processor. `x86_64` is for Intel and AMD processors; `arm64` is for ARM processors, including Apple Silicon and Windows on ARM.

| System | Processor | Files |
| --- | --- | --- |
| Windows | x86_64 | `Daily-CF-0.3.25-windows-x86_64-nsis.exe` (installer), `Daily-CF-0.3.25-windows-x86_64-portable.exe` (portable) |
| Windows | ARM64 | `Daily-CF-0.3.25-windows-arm64-nsis.exe` (installer), `Daily-CF-0.3.25-windows-arm64-portable.exe` (portable) |
| macOS | Intel | `Daily-CF-0.3.25-macos-x86_64.dmg`, `Daily-CF-0.3.25-macos-x86_64.zip` |
| macOS | Apple Silicon | `Daily-CF-0.3.25-macos-arm64.dmg`, `Daily-CF-0.3.25-macos-arm64.zip` |
| Linux | x86_64 | `Daily-CF-0.3.25-linux-x86_64.AppImage`, `Daily-CF-0.3.25-linux-x86_64.deb` |
| Linux | ARM64 | `Daily-CF-0.3.25-linux-arm64.AppImage`, `Daily-CF-0.3.25-linux-arm64.deb` |

On Windows, run the installer or open the portable version directly. On macOS, open the DMG and copy the app to Applications, or extract the ZIP. On Linux, make the AppImage executable before opening it; DEB packages are for Debian and Ubuntu systems.

GitHub's automatically generated source archives contain the source code, not an installed application.

### Updating from the app

The updater keeps the running app's architecture: an `x86_64` build receives `x86_64`, even when running through emulation. Windows portable stays portable; Windows installed builds receive NSIS installers. Linux AppImage and DEB builds keep their package type. macOS builds receive a DMG whether originally installed from a DMG or ZIP. Development builds and unrecognized package types offer the release page.

After verification, Windows installers, macOS DMGs and Linux DEBs can be opened with the operating system. Follow the installer or package manager to finish. The confirmation warns about unsaved changes, and the current app stays open. For portable and AppImage downloads, show the file, quit the old app and replace it yourself. The downloaded AppImage is given executable permission.

Checking and downloading an app update are separate from refreshing the problem library. Neither requires permission to submit solutions or changes your fork.

### Checksums and signatures

`SHA256SUMS.txt` lists the checksums of all twelve packages. Filenames use `windows`, `macos`, or `linux` for the system and `x86_64` or `arm64` for the architecture. The updater checks the package before offering it and again before opening or showing it. A checksum detects corruption or a mismatch with the published file; it is not an independent publisher signature.

Windows packages are unsigned. macOS apps use an ad-hoc signature, without an Apple Developer ID certificate or notarization. The operating system may show a security warning. The updater does not bypass these checks.

### Validation and limits

Local verification on Windows passed 2,118 automated tests; one symbolic-link test was skipped. The TypeScript, renderer and main-process builds passed, and a native smoke check confirmed that the updater bridge returned its initial state.

Browser UI checks with simulated update responses covered Chinese and English, checking, downloading, cancellation, retry, verified downloads, installer confirmation and unsaved-change warnings. The portable layout was checked at the normal viewport width and the AppImage layout at 900 pixels. A live GitHub check verified the twelve v0.3.24 asset URLs and matched their published digests against the release checksum list; it did not download or install those packages.

The release workflow checks packaged executable architectures, bundled application files and installer names, and starts supported targets. Cross-platform installation and upgrading have not been independently tested on every supported system and architecture.

The updater opens an installer or provides a verified file; it does not perform an unattended replacement. Installer behavior and OS security prompts still depend on the platform. An automated test pass does not replace installing and updating every package on its corresponding device.

## 简体中文

此版本新增**设置 → 软件更新**。可以检查最新版本、查看发布说明，再选择下载适合当前系统、架构和安装形式的文件，无需登录 GitHub。

下载会显示进度，支持取消和重试，并核对文件的完整大小和 SHA-256。打开下载的安装程序需要再次确认，客户端不会静默安装或自行重启。免安装版和 AppImage 下载完成后，由用户退出程序再替换。0.3.24 没有更新功能，因此需要先手动安装一次 0.3.25，之后才能用此功能获取后续版本。

### 下载

请根据操作系统和处理器选择安装包。`x86_64` 适用于 Intel 和 AMD 处理器；`arm64` 适用于 ARM 处理器，包括 Apple Silicon 和 Windows on ARM 设备。

| 系统 | 处理器 | 文件 |
| --- | --- | --- |
| Windows | x86_64 | `Daily-CF-0.3.25-windows-x86_64-nsis.exe`（安装版）、`Daily-CF-0.3.25-windows-x86_64-portable.exe`（免安装版） |
| Windows | ARM64 | `Daily-CF-0.3.25-windows-arm64-nsis.exe`（安装版）、`Daily-CF-0.3.25-windows-arm64-portable.exe`（免安装版） |
| macOS | Intel | `Daily-CF-0.3.25-macos-x86_64.dmg`、`Daily-CF-0.3.25-macos-x86_64.zip` |
| macOS | Apple Silicon | `Daily-CF-0.3.25-macos-arm64.dmg`、`Daily-CF-0.3.25-macos-arm64.zip` |
| Linux | x86_64 | `Daily-CF-0.3.25-linux-x86_64.AppImage`、`Daily-CF-0.3.25-linux-x86_64.deb` |
| Linux | ARM64 | `Daily-CF-0.3.25-linux-arm64.AppImage`、`Daily-CF-0.3.25-linux-arm64.deb` |

Windows 用户可以运行安装程序，或直接打开免安装版。macOS 用户可以打开 DMG，将应用复制到“应用程序”文件夹，或解压 ZIP。Linux 用户需要先为 AppImage 添加执行权限再打开；DEB 安装包适用于 Debian 和 Ubuntu 系统。

GitHub 自动生成的源码压缩包包含源代码，不是可直接使用的客户端。

### 在应用内更新

更新功能保留当前程序的架构：`x86_64` 版本仍下载 `x86_64`，即使正通过模拟运行。Windows 免安装版仍下载免安装版，安装版下载 NSIS 安装程序。Linux AppImage 和 DEB 保留各自的安装形式。macOS 均下载 DMG，无论原本从 DMG 还是 ZIP 安装。开发构建或无法识别的安装形式提供发布页入口。

校验完成后，Windows 安装程序、macOS DMG 和 Linux DEB 可以交给系统打开，再按照安装程序或软件包管理器的步骤完成更新。确认窗口会提醒未保存的修改，当前客户端仍保持运行。免安装版和 AppImage 可以打开文件所在位置，退出旧版本后自行替换。下载的 AppImage 会设置执行权限。

软件版本检查和下载与刷新题库相互独立，均不需要投稿权限，也不会修改 Fork。

### 校验与签名

`SHA256SUMS.txt` 列出了全部 12 个安装包的校验值。文件名中的系统使用 `windows`、`macos` 或 `linux`，架构使用 `x86_64` 或 `arm64`。更新功能在提供文件前进行校验，打开文件或显示所在位置前还会再次校验。校验值可以发现损坏或与发布文件不一致的情况，不是独立的发布者签名。

Windows 安装包未签名。macOS 应用使用临时签名（ad-hoc），没有 Apple Developer ID 证书，也未经过公证。操作系统可能显示安全提示，更新功能不会绕过这些检查。

### 验证与限制

Windows 本地验证通过了 2,118 项自动测试，一项符号链接测试跳过。TypeScript 检查、界面与主进程构建通过，原生启动检查确认更新功能的接口能返回初始状态。

使用模拟更新响应进行的浏览器界面检查覆盖了中英文、版本检查、下载、取消、重试、校验完成、打开安装包确认和未保存修改提醒，还在正常视口宽度下检查了免安装版界面，在 900 像素宽的视口下检查了 AppImage 界面。实际 GitHub 请求核对了 v0.3.24 的 12 个文件链接，并确认发布的摘要与校验清单一致；没有下载或安装这些文件。

发布流程会检查打包后可执行文件的架构、应用文件和安装包名称，并启动支持的构建目标。尚未在全部支持的系统和架构上分别完成安装与升级测试。

更新功能负责打开安装程序或提供经过校验的文件，不会自动完成替换。安装程序的行为和系统安全提示仍取决于平台。自动测试通过不能替代在对应设备上对每种安装包进行安装和更新测试。
